# 作業引き継ぎ（2026-11-08）

## 目的と開発ルール

このリポジトリは、iPhone 16を対象としたオンデバイス英語学習アプリと再利用可能な音声AI基盤を実装する。全体仕様は [Specification-v1.md](Specification-v1.md)、フェーズと実機確認の状況は [Status.md](Status.md) を参照する。

- ローカルのコンパイラ、パッケージ、テストはDocker内で実行する。標準コマンドは `bash Scripts/test.sh` と `bash Scripts/quality.sh`。
- 開発ホストはLinux。iOS Simulator・アーカイブ・UI検証はGitHub ActionsのmacOS runnerで行う。
- `codex/` ブランチで作業し、PRの必須チェックが通ってからマージする。mainへ直接pushしない。
- 個人データ、音声、モデル重み、証明書、プロビジョニングプロファイル、秘密鍵をGitに含めない。クラウド推論や利用者コンテンツのログを追加しない。
- TestFlightへ配布する場合はPRに `testflight` ラベルを付ける。ラベルなしのマージではアップロードされない。署名と配布の詳細は [TestFlight.md](TestFlight.md)。
- 各節目（フェーズ完了、機能群完了、実機検証完了）で、この `Docs/` 配下に実装内容・検証結果・未確認事項を更新または追記する。Docker/CIの合格を実機推論の証明として扱わない。

## 利用者依頼と実装中の変更

利用者はモデルのダウンロードが完了したと報告している（どのモデルを指すかは未確認）。アプリのアクセス導線と録音後の結果表示を次のように改善する。

1. **ASRモデル管理の設定導線**：ParakeetなどのASRモデルを、Kokoro / Pocket TTSなどと同様に設定画面から確認・ダウンロード・管理できるようにする。利用者は「他のモデルは設定からなので同じように」と要望している。
2. **教材画面の練習モード切替**：「リスニング」と「スピーキング」を画面上部に横並びのタブ/セグメントとして置き、教材詳細から画面を離れずに切り替えられるようにする。現在のmainでは「スピーキング練習・文字起こし」へのNavigationLinkが教材画面の下部にある（`Apps/EnglishTrainer/EnglishTrainerApp.swift`）。
3. **録音後の結果確認**：スピーキング画面では録音操作が上部、RE-USE操作が中間、文字起こし・評価が下部にある。録音完了後、利用者が画面を手動でスクロールせずに文字起こし結果と評価を確認できるようにする。録音停止後の認識開始、進行中表示、エラー、RE-USE比較結果との表示関係も明確に保つ。
