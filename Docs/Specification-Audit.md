## 今回まとめて実装している範囲

教材を学習する通常の画面に設問・選択肢・回答と解説を組み込み、回答時点の設問・選択肢・正誤・教材版を保存する。教材を修正しても過去の回答は保持し、新しい版では再回答する。生成元・生成日時と利用者の修正日時を分ける。

教材の修正、非表示と再表示、端末内の問題メモ、カテゴリ・難易度・TOEIC Partによる検索と分類、次の教材への移動を追加する。非表示教材は通常一覧と復習予定から除外するが、履歴・音声・保存データを削除しない。音声生成モデルやメモリ制御の変更は行わない。

「次の教材」などで移動したとき、別教材の保存録音を自動で採点しない。録音に教材IDを付け、異なる教材や旧版の対応不明な録音は明示的に比較操作を選んでもらう。元録音は保持する。

保存領域はschema migration 4で教材設定と設問回答テーブルを追加する。旧LearningItem JSONはカテゴリ等がない場合も復元できる。アプリ全学習データ削除は新テーブルも消す。
