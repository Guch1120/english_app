## Operating and release notes

- Run local tests and quality checks inside Docker with `bash Scripts/test.sh` and `bash Scripts/quality.sh`. Never install the iOS SDK on the Linux host.
- PR CI runs on GitHub macOS for package tests, iOS Simulator build/analyze, unsigned distribution archive checks, and the review gate. Only PRs labeled `testflight` before merging to `main` trigger the protected TestFlight upload. Manual uploads remain available from Actions.
- The short version is **0.1.0**; the latest successful upload is **154.1** from TestFlight workflow run #54. The user confirmed updating to 151.1; availability and installation of the newer 154.1 build remain unconfirmed. The build number follows `(workflow run number + 100).attempt`. TestFlight automatic updates are controlled by the tester in the TestFlight app; App Store Connect can automatically distribute new builds to an internal group. See [TestFlight.md](TestFlight.md), [Apple's TestFlight automatic-update guide](https://developer.apple.com/videos/play/wwdc2023/10012/?time=52), and [Apple's internal testing guide](https://developer.apple.com/testflight/).
- Signing secrets remain in the GitHub `ios-testflight` environment. Do not commit learning data, audio, model weights, certificates, provisioning profiles, or private keys.
