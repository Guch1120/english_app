# 教材の学習・修正・管理

学習タブと設定の「教材を探す・管理」から、英文・訳、単語/フレーズ/文章/会話、難易度、TOEIC Part 1〜4で教材を探せる。自分の英文を追加するときも任意の分類を設定でき、教材画面から次の教材へ進める。既存教材は分類なしのデータも引き続き読める。

## 設問と履歴

生成教材の設問は通常のリスニング画面から回答する。選択前に正解は表示せず、回答を確認した後に正誤、正解、解説を表示する。生成内容の意味的な正しさは保証しないため、疑問があれば教材を修正・問題メモへ記録できる。

回答は当時の設問・選択肢・回答・正解・日時・教材の更新日時とともにSQLiteへ保存する。アプリを再起動しても復元される。修正後は新しい教材版として再回答し、以前の回答は学習履歴に残す。これは設問への回答であり、発音スコアではない。

## 修正・非表示・問題メモ

教材画面右上の「教材の操作」から以下を行う。

- 教材を修正：英文・訳・分類を編集する。生成教材では設問・選択肢・正解・解説・対象語句も編集し、構造検証を通った内容だけ保存する。生成元モデル・生成日時を保持し、利用者の修正日時を別に記録する。
- 教材を非表示：通常の教材一覧と復習予定から除外する。保存データと履歴を削除しない。管理画面で「非表示の教材も含める」を有効にし、教材を開いて再表示できる。
- 問題を記録：2000文字以内の端末内メモ。外部の報告サービスへ送信しない。「問題メモのある教材のみ」で探せ、メモを空にして保存すれば記録を解除する。

設定の全学習データ削除は、教材設定と設問回答も削除する。メモと設問回答は他の学習データと同じ保護されたSQLiteに保存し、通常ログに含めない。

## 保存録音との関係

録音に教材IDを対応付け、別教材へ移動したときに以前の文字起こしを新教材の評価として自動表示しない。以前の録音や旧バージョンで対応情報がない録音は保持する。「保存録音をこの教材と比較」を明示的に選ぶと再認識して比較する。RE-USE比較は対応する録音がある場合だけ有効になる。

## 移行と検証

schema migration 4は既存テーブルを破棄せず、`lesson_preferences` と `quiz_attempts` を追加する。LearningItemの新しいカテゴリ・難易度・Partが旧JSONにない場合も復元する。生成教材と学習本文の修正、設問回答と学習イベントは、それぞれトランザクションで保存する。

Dockerでは旧schema 3のDBからの移行、再起動復元、修正時の帰属情報・履歴保持、不正データ拒否、回答と操作履歴の原子性、全削除を検証する。Simulator UIは明示的なDebug専用教材を使い、モデルを取得せず回答、修正後の履歴保持、問題メモ、非表示と再表示を検証する。テスト教材はReleaseと物理iPhoneのビルドでは生成しない。

物理iPhoneでの更新時のDB移行、長い教材・Dynamic Type、保存録音と教材の切替は別途確認が必要。
