# 画面構成とUI設計

2026-11-11のGUI改修で整理した画面構成。仕様書14章（音声再生・録音を大きく、学習中の操作を最小限、AIモデル比較は通常学習と分離）に沿う。学習ロジック・推論・保存形式は変更していない。

## 改修前の課題

iPhone 16 / TestFlight 208.1 の実機画面とソースを確認して判断した。

| 画面 | 課題 |
|---|---|
| 学習（ホーム） | 表示が復習件数だけ。教材追加フォームが一覧の最下部にあり教材が増えるほど遠くなる。AI教材生成が設定の中にしかない |
| リスニング | 音声エンジン選択が最上部を占め、再生・停止・一時停止・再開が4行に分散。単語選択が横スクロール |
| スピーキング | 録音ボタンが通常の行と同じ大きさで、認識モデル設定より下にある |
| 復習 | 音声設定と統計7行が先頭にあり、今日の復習はスクロールしないと見えない。保存済み1件が4行を使う |
| 設定 | 性質の違う9リンクが1セクションに混在。診断ログ（最大500件）が設定画面に直接並ぶ。発熱状態が内部の列挙名のまま |

## 画面構成

タブは 学習 / 復習 / 設定 の3つのまま。

**学習（ホーム）**

1. サマリーカード：今日の復習件数・連続学習日数・教材数。復習があれば「今日の復習を始める」で復習タブへ移動
2. 操作タイル：「英文を追加」（シートで入力）と「AIで教材を生成」（LLM教材生成画面）
3. リスニング教材の一覧：カテゴリ・難易度・TOEIC Partをチップ表示、英文は3行まで
4. 教材を探す・管理

**教材（リスニング）**

1. お手本を再生（大きな主ボタン）、その下に 一時停止 / 再開 / 停止 を1行、読み上げ速度（標準へ戻すボタン付き）、繰り返し
2. スクリプト：英文と日本語訳の表示切り替え（初期状態は非表示のまま）
3. 設問（生成教材のみ）
4. 苦手箇所を保存：英文表示中は単語チップが折り返して全語が見える
5. お手本の音声（エンジン・話者）、次の教材

**教材（スピーキング）**

1. お手本
2. 録音して話す（大きな主ボタン。録音中は赤い停止ボタン）。認識を使えないときは理由と準備場所を表示
3. 文字起こし・評価：誤り率、認識文、色付きの単語チップ（緑=一致、橙=違い）、詳細は折りたたみ
4. 音声認識モデル、音声強調の比較（RE-USE）

**復習**

1. 今日の復習：項目ごとに再生ボタンと4段階評価（色分け）
2. 学習の記録：統計タイルと復習履歴
3. 保存済み：習熟度と次回予定。削除は行末のゴミ箱ボタン（確認ダイアログあり）
4. 復習の音声

**設定**

- 音声とAI：音声 / ASR / LLM / RE-USE のモデル管理
- モデルの比較と確認：TTS聴き比べ、ASR比較、オフライン準備、AIモデル情報
- 教材、データとプライバシー（録音保持・全データ削除）
- アプリと端末：バージョン等と「端末内診断」（診断ログと共有は専用画面）

## 共通部品

`Apps/EnglishTrainer/DesignSystem.swift` に表示専用の部品を置く：折り返しレイアウト `FlowLayout`、`Chip`、`StatTile`、`ActionTile`、`TransportButton`、`PrimaryActionLabel`。学習・推論ロジックは含めない。色はシステムカラーのみを使い、ライト／ダークの両方に追従する。

## 検証範囲と未確認事項

- Simulator UIテスト（Validate workflow）を新しい画面構成に合わせて更新した。アクセシビリティ文字サイズでの録音ボタン到達性の検査は維持している。
- 2026-11-11、iPhone 16 / iOS 26.4.2 / TestFlight 0.1.0 (231.1) でWDAのスクリーンショットにより、学習・英文追加シート・リスニング・スピーキング・復習・設定の各画面が新しい構成で表示されることを確認した（ダークモード、標準文字サイズ）。この確認で見つけた表示上の問題（ホームのサマリーカードの上下が切れる、主ボタンのアイコンが出ない、統計タイルが1枚だけ次の行に余る、英文追加シートの題名が省略される）は後続PRで修正した。
- 2026-11-12、同じ端末の TestFlight 0.1.0 (232.1) で、上記4点の修正（サマリーカードが3列で全体表示、主ボタンのアイコン表示、統計タイルが4枚＋3枚の2行、追加シートの題名が全文表示）と端末内診断画面の表示を確認した（ダークモード、標準文字サイズ、見た目のみ）。この確認で残った点（統計タイルの見出しが語の途中で折り返す、診断記録の発熱状態が英語の生値、診断ログ消去のアイコンだけ色が違う）は後続PRで修正した。その修正後の画面は実機では未確認。
- 復習の統計は「継続の記録」4枚と「練習回数」3枚の固定2行。4列側は幅が狭いため見出しを4文字に短縮し、VoiceOverには元の文言を読ませる。アクセシビリティ文字サイズではどちらの行も2列になる。
- 実機で未確認：ライトモード、アクセシビリティ文字サイズ、VoiceOver読み上げ順、片手操作のしやすさ、同じ行に並べたボタンの実タップ。
